# Mobile Controls Components

Этот набор компонентов добавляет поддержку мобильного управления для игры.

## Компоненты

### 1. MobileInputComponent
Компонент для обработки сенсорного ввода:
- Левый джойстик - управление движением персонажа
- Правый джойстик - управление направлением атаки/прицеливания
- Кнопка огня (красная) - автоматическая стрельба
- Кнопка рывка (зелёная) - быстрый рывок в направлении

**Расположение на экране:**
- Джойстик движения: слева снизу
- Джойстик прицеливания: справа снизу
- Кнопка огня: справа над джойстиком прицеливания
- Кнопка рывка: левее кнопки огня

### 2. DashComponent
Компонент для реализации механики рывка:
- Настройка скорости, длительности и перезарядки рывка
- Поддержка направления рывка (по движению или по прицеливанию)
- Сигналы для интеграции с UI (кулдаун, состояние)

### 3. MobileControlsController
Связующий компонент, который координирует работу мобильных контролов:
- Обрабатывает нажатие кнопки рывка
- Определяет направление рывка (приоритет: прицеливание → движение → дефолтное)
- Управляет состоянием кнопки огня

## Установка

### Вариант 1: Автоматическая установка через код
Добавьте следующие компоненты к игроку (CharacterBody2D):

```
Player (CharacterBody2D)
├── InputComponent
│   └── MobileInputComponent (добавляется только для мобильных устройств)
├── DashComponent
├── MobileControlsController
├── MovementComponent
└── ... другие компоненты
```

### Вариант 2: Ручная установка в редакторе Godot

1. Откройте сцену игрока (`simple_character.tscn`)
2. Добавьте дочерний узел `Node` к `SimpleCharacter`
3. Привяжите скрипт `DashComponent.gd`
4. Настройте параметры рывка (скорость, длительность, кулдаун)
5. Добавьте ещё один дочерний узел `Node` 
6. Привяжите скрипт `MobileControlsController.gd`
7. К узлу `InputComponent` добавьте дочерний узел `Node2D`
8. Привяжите скрипт `MobileInputComponent.gd`

## Настройка

### Параметры MobileInputComponent:
- `move_joystick_range` - радиус джойстика движения (по умолчанию 50)
- `aim_joystick_range` - радиус джойстика прицеливания (по умолчанию 50)
- `joystick_deadzone` - мёртвая зона джойстиков (по умолчанию 0.1)
- `move_joystick_position` - позиция джойстика движения
- `aim_joystick_position` - позиция джойстика прицеливания
- `fire_button_position` - позиция кнопки огня
- `dash_button_position` - позиция кнопки рывка

### Параметры DashComponent:
- `dash_speed` - скорость рывка (по умолчанию 800)
- `dash_duration` - длительность рывка в секундах (по умолчанию 0.15)
- `dash_cooldown` - время перезарядки в секундах (по умолчанию 2.0)
- `dash_direction_mode` - режим направления (0 = движение, 1 = прицеливание)

## Работа на ПК

На ПК мобильные компоненты автоматически отключаются и не обрабатывают ввод.
Игра продолжает работать с клавиатурой и мышью как обычно.

## Интеграция с существующим кодом

Компоненты спроектированы так, чтобы быть максимально ненавязчивыми:
- `InputComponent` автоматически обнаруживает мобильное устройство
- `DashComponent` опционален и не требуется для базовой функциональности
- `MobileControlsController` сам находит нужные компоненты при старте

## Расширение

Для добавления новых функций:
1. Расширьте `MobileInputComponent` новыми сигналами
2. Обработайте сигналы в `MobileControlsController`
3. При необходимости добавьте новые компоненты в папку `mobile_controls/`
